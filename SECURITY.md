# Security policy

Do not disclose vulnerabilities, API keys, private keys, identity documents or customer data in public issues. Contact the maintainers privately through GitHub's **Report a vulnerability** flow when enabled, or another private channel listed by the repository owner.

This repository is a development sandbox. Paystack accepts test keys only; QIE settlement and real-money payouts are not enabled. Rotate any credential posted in chat, an issue, a log or a commit. A sandbox is not suitable for custody or production financial services.
