The `phase-*` documents and `reference/` PDFs record earlier Kora-era sandbox work. They are retained for technical and audit history; their product language and feature descriptions are not the current Microsendr launch contract.

The default CI gate runs current Personal browser tests. Older Business, auth,
network, rail, Stellar and controls browser suites preserve historical scenarios
but still assert retired screens; they are not current product acceptance tests.
